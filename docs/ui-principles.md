# Strata UI 원칙 — 2026-09-18 개정

- 조회와 정리는 단일 화면에서 이어진다. 코어 선택은 실제 폴더 영역의 내역을 표시한다.
- 코어 영역 선택 시 경로가 확인된 후보만 영역에 연결한다. 위치 미확인 도구는 별도 Mac 전체 후보로 표시하고 다른 영역의 선택 개수를 알린다. 명령 기반 리소스를 근거 없이 폴더에 귀속시키지 않는다.
- 스캔 중단 시 중간 측정은 최종 결과로 사용하지 않는다. 정리 이력은 스캔 없이 열 수 있다.
- 용량 카드, 사용량, 미분류 용량, 코어의 여유 공간은 같은 스냅샷과 가용 용량 기준을 사용한다.
- 일반 여유 공간 API가 없을 때만 회수 가능 공간이 포함될 수 있는 가용 용량을 사용하고 ‘사용 가능’으로 구분한다.
- 권한은 첫 사용 때 설명하며 재확인과 제한 모드를 제공한다. 권한 확인은 보호 폴더 읽기 검사이지 전체 파일 접근의 보증이 아니다.
- 보호 폴더 읽기 확인과 일부 경로 측정 실패는 별도 상태로 표시한다. 파일 읽기 오류만으로 권한 미승인을 암시하지 않는다. 측정 실패 수는 각 측정 영역에서 경로 중복을 제외한 수이며, 권한을 변경한 후에는 다시 스캔해야 한다.
- 미분류 공간은 권한 외에도 스냅샷·공유 블록·측정 시점 등 여러 원인의 영향을 받는다. 권한만으로 해소를 보장하지 않는다.
- 컨셉은 색과 질감에 남긴다. 메뉴·제목·버튼은 ‘내 저장공간’, ‘정리할 항목’, ‘먼저 확인’ 등 사용자 언어를 쓴다.
- 층의 깊이를 파일 나이 또는 삭제 안전도로 해석하지 않는다. 폴더 전체에 안전 등급을 부여하지 않는다.
- 선택 목록에는 왼쪽 체크 표시와 구분선을 쓴다. 선택 타깃은 작은 체크 표시가 아니라 행 전체다.
- 정리 후보의 폴더 이름만으로 재생성 가능성을 확정하지 않는다. 프로젝트 근거 부족·읽기 실패 항목은 주의로 분류하고 기본 선택에서 제외한다. 근거가 있어도 사용자 파일이 없다는 보증은 하지 않는다.
- 미분류 진단 본문에는 용량과 다음 행동만 간결히 남긴다. 쉬운 설명은 15pt 본문의 별도 팝업에, 전문적인 측정 자료는 팝업 안의 접힌 영역에 둔다.
- 상세 정보·복사는 선택 버튼과 독립시켜 실수로 선택이 바뀌지 않게 한다.
- 작업 바는 스크롤 밖 하단에 고정한다. 0개 선택이어도 안내와 비활성 버튼을 보여준다.
- 예상 후보 용량을 주요 지표로 보여주되 실제 확보 공간이라고 보장하지 않는다. 휴지통 이동, 즉시 삭제, 재다운로드 영향을 구분한다.
- 정리 이력은 성공·휴지통 이동 건수와 디스크 여유 공간의 부호 있는 변화를 분리한다. 감소를 0으로 보정하지 않으며 변화 없음과 측정 불가를 구분한다. 과거의 모호한 0은 측정 불가로 처리하고 저장 파일은 재작성하지 않는다.
- 상세 측정 설명은 정보 버튼에서 제공한다. 짧은 상태와 측정 시각은 코어에 유지한다.
- 현재 사용자 휴지통은 상위 사용자 영역에서 해당 경로를 제외하고 별도로 측정한다. 양수인 휴지통은 작아도 기타 영역에 합치지 않는다. 빈 휴지통은 0 KB, 접근 불가는 측정 불가, 일부만 읽은 경우 최소 용량으로 구분하며 0바이트에 임의의 코어 두께를 부여하지 않는다.
- 별도 휴지통 항목은 현재 사용자·측정 볼륨 범위만 다룬다. 다른 사용자와 외장 디스크의 휴지통은 포함하지 않으며 휴지통 비우기를 실행하지 않는다. 공유 블록과 영역 간 하드 링크까지 물리적으로 중복 제거한 용량을 보장하지 않는다.

## 역할별 색상 — 2026-09-21

- 무채색 바탕 위에 선택·행동은 청록(accent), 처리 성공은 녹색(success), 재확인·건너뜀은 호박(warning), 정보·확인 불가는 자주(info), 오류는 장밋빛(error)을 쓴다.
- 처리 성공과 삭제 안전 등급은 다르다. 안전·주의 등급은 중립 아이콘과 문구를 유지하며, 되돌릴 수 없는 작업에는 별도 irreversible 토큰을 쓴다.
- 작은 글자는 장식용 광물 팔레트 대신 Text 토큰을 사용한다. Surface는 불투명한 모드별 배경색으로 정의하고 선택 경계는 accentBorder로 표시한다.
- 주요 버튼은 actionFill/actionForeground/actionHover 조합을 사용한다. 임의의 흰색·검정색 글자를 지정하지 않는다.
- 코어의 광물색을 라벨에도 연결하되 색뿐 아니라 위치·이름·질감을 함께 사용한다. 색이나 깊이는 삭제 안전도를 뜻하지 않는다.
- ThemeContrastTests는 Aqua/Dark Aqua에서 실제 색상을 해석해 역할별 글자/배경과 버튼 조합 4.5:1, 선택 테두리 3:1을 검사한다. 이것만으로 앱 전체 접근성 검증을 완료한 것은 아니다.
