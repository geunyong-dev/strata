# 본인 Mac용 설치본

## 패키징

저장소 루트에서 `bash scripts/package-local.sh`를 실행한다. 기본 결과는 숨김 폴더가 아닌 `dist/Strata.app`이다. 기존 결과가 있으면 덮어쓰지 않고 중단한다. 새 결과 경로는 절대 경로로 전달할 수 있다.

- Release 구성으로 현재 Mac 아키텍처를 빌드한다.
- macOS 14 이상, 버전 0.1.0 / 빌드 8.
- 기존 로컬 앱 식별자 `local.strata.design-review`를 유지한다.
- 실행 파일을 복사한 다음 Info.plist를 포함한 앱 번들 전체를 ad-hoc 서명하고 검증한다.
- 외부 배포용 Developer ID 서명·공증은 하지 않는다. 다른 Mac 배포용이 아니다.
- 지층·코어 시료 형태의 전용 앱 아이콘을 포함한다. 원본은 `Packaging/AppIcon/strata-icon-v1.png`, 패키징용은 `Packaging/AppIcon/Strata-v1.icns`이며, 번들의 `Contents/Resources/Strata.icns`와 `CFBundleIconFile`로 연결한다.
- `Contents/Helpers/StrataReadOnlyScanner`를 별도 서명한 뒤 번들 전체를 서명한다. 도구를 시스템에 설치하거나 상주시킬 필요는 없다.

## 관리자 정밀 검사

일반 검사 후 상단에 측정 불가 경로가 있으면 **정밀 검사**를 누른다. 안내창에서 시작하면 일반 검사 이후 macOS 관리자 인증을 요청한다. 인증 취소·도구 실행 실패 시 일반 검사 결과를 유지한다.

- 읽기 전용 일회성 도구로 Data 볼륨의 Library, private, System 및 `.fseventsd`, `.Spotlight-V100`, `.DocumentRevisions-V100`만 재측정한다. 사용자 홈·외장 디스크·삭제 기능은 승격하지 않는다.
- 도구는 파일 내용을 열지 않고 메타데이터와 폴더 목록만 읽는다. 임의 명령·스캔 경로를 인수로 받지 않는다. 심볼릭 링크와 하위 마운트는 따라가지 않는다.
- 앱은 실행 전 번들 서명을 검사한다. 임시 검사 토큰(소유자 전용 0700/0600)을 제거하면 도구는 다음 순회 단계에서 종료한다. 정상 제한 180초, 시스템 호출 지연에 대비한 강제 제한 200초가 있다. 인증 대기 시간은 별도다.
- 관리자 측정은 기존 영역에 더하지 않고 전체 영역 단위로 교체한다. 미완료·용량 감소 또는 동일 용량에서 오류가 증가한 측정은 반영하지 않는다. 사용자 데이터와 휴지통 측정은 그대로 유지한다.
- 추가로 확인한 용량은 회수 가능 공간이 아니다. 관리자 권한과 전체 디스크 접근은 다르며 일부 보호 영역은 남을 수 있다. 정밀 검사 후 새 하위 경로를 탐색하면서 오류 경로 수가 늘 수도 있다.
- 기존 스캔 로그에 `scan_mode`, `administrator_scan_started`, `administrator_area`, `administrator_scan`, `administrator_summary`를 남긴다. 관리자 오류의 경로와 POSIX 코드, 반영 상태를 확인할 수 있다.
- 로컬 개발용 ad-hoc 설치본이다. 외부 배포 시 Developer ID 서명·공증 및 권한 요청 UX 검증이 별도로 필요하다.

## 설치 및 실행

1. 실행 중인 개발용 Strata를 종료한다.
2. `dist/Strata.app`을 사용자 응용 프로그램 폴더(`~/Applications`)에 복사한다. 기존 설치본이 있으면 먼저 위치와 버전을 확인하고 백업한다.
3. Finder의 **이동 → 폴더로 이동**에서 `~/Applications`를 열고 Strata를 실행한다.
4. 전체 디스크 접근이 필요하면 시스템 설정의 개인정보 보호 및 보안에서 **설치한 앱**을 추가한다. 앱을 종료 후 다시 열고 재스캔한다.

개발용 `.build/Strata.app`과 설치본을 동시에 실행하지 않는다. 동일 식별자만으로 접근 권한 유지를 보장할 수 없으며, 특히 ad-hoc 서명은 빌드가 바뀌면 권한 재승인이 필요할 수 있다. 시스템 권한을 자동 수정하거나 Gatekeeper를 해제하지 않는다.

## 실제 UI 확인 항목

- 빌드 7: 다시 스캔하면 코어에 시스템·다른 볼륨을 구분한다. 코어의 해당 라벨이나 ‘시스템·미분류 공간 → 자세히 알아보기’에서 운영체제·시동·복구·가상 메모리 등의 내역을 볼 수 있다. 측정값 불일치 시 ‘비교 보류’로 표시한다.
- Spotlight 등 기존 폴더의 경로·삭제 정책은 바꾸지 않고 사용자에게 보이는 이름과 설명만 개선했다. Spotlight 전체 용량을 확인하려면 일반 검사 후 필요 시 정밀 검사를 사용한다.

- 첫 실행, 권한 안내·제한 모드 진행, 권한 변경 후 재시작·재스캔
- 검사 준비부터 경과 시간 표시, 실시간 코어 갱신, 중단, 재검사
- 완료 시간 고정 표시, 휴지통 상태, 영역 선택
- 미분류 진단 팝업 열기·닫기·기술 근거 펼치기
- 정리 후보 행·그룹 선택, 접기, 근거, 확인 문구 입력 (실행하지 않고 취소)
- 정리 이력, Light/Dark, 최소 창 크기, 스크롤
- Tab/Shift-Tab/Space/Escape, 포커스 표시, VoiceOver, 동작 줄이기
- 업데이트 후 실행 및 권한 유지

실제 사용자 파일 정리, Docker 리소스 삭제, 시뮬레이터 삭제는 UI 검증에 사용하지 않는다. 삭제 검증이 필요하면 별도 테스트 파일과 명확한 경로로 범위를 제한한다.
